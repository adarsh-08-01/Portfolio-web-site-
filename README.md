# Adarsh Kashyap — Creative Artsy Portfolio Website 🎨📱

A vibrant, high-energy, "Creative Artsy" portfolio website inspired by [portfoliofy.io/preview/creative-artsy](https://portfoliofy.io/preview/creative-artsy) created for **Adarsh Kashyap** (iOS Developer, Video Editor, Graphic Designer & Creative Tech Enthusiast).

🔗 **Live Site:** [heyadarsh.vercel.app](https://heyadarsh.vercel.app/)

---

## 🚀 Features & Scrapbook Design System

- **Scrapbook Aesthetic**: Warm paper cream canvas background (`#FDFBF7`), ink black borders (`#191510`), paper grain texture, floating adhesive tape clips, and handwritten accent fonts (`Just Me Again Down Here`).
- **Vibrant Color Palette**: Electric Yellow (`#FFD600`), Royal Blue (`#2979FF`), Hot Magenta (`#FF4081`), Fresh Mint Green (`#00E676`), and Warm Orange (`#FF6D00`).
- **Animated Splash Screen**: Custom greeting bubble ("*Oh, hello! You found me!*") with auto-dismissal.
- **Hero & Profile Showcase**:
  - Handwritten label & doodle display frame ("ADARSH KASHYAP").
  - Floating sticker pills ("iOS Developer", "Video Editor", "Graphic Designer", "SwiftUI & AI").
  - Availability status pill ("🟢 Open to new work & good problems").
- **About & Skills Scrapbook**:
  - Interactive skill pills with jagged clip-path background shapes (`polygon(...)`).
  - Animated emoji toggle effect on hover (`📱 ⚡`, `🎬 ✂️`, `🎨 ✨`, `⚙️ 🧠`).
- **Featured Works**:
  - **RK Construction**: Live website banner & client preview card (`https://rkconstruction11.in/`).
  - **SangeetStream**: Interactive web audio player widget with real-time play/pause controls, seek bar, and track switcher.
- **iOS App Showcase (Demo & Screenshot Ready)**:
  - Filterable category grid (`All`, `iOS SwiftUI Apps`, `Web Apps`, `Video & Motion`).
  - Native iPhone mockup frames with notch & screen graphics.
  - Native HTML `<dialog id="app-dialog">` top-layer modal popup with `@starting-style` entry animations.
- **Swift & C Code Playground**:
  - Tabbed code viewer for SwiftUI components and C algorithms.
  - One-click copy code snippet button.
- **Direct Contact Banner**: Instant WhatsApp direct chat button (`+91 6390790801`) & email trigger (`adarshk.work.0801@gmail.com`).

## 📂 File & Folder Structure

```
portfolio main/
├── index.html              # Main HTML5 single-page application
├── style.css               # Design tokens, Creative Artsy themes, keyframes & modal animations
├── app.js                  # Application controller: splash intro, modals, audio player, code tabs
├── README.md               # Documentation & setup instructions
├── assets/
│   ├── images/             # Folder to drop your iOS App screenshots (e.g. app_just_sip_1.png)
│   └── icons/              # Custom SVG doodle icons and social badges
└── js/
    ├── data.js             # Project metadata, skills list, app showcase items & code snippets
    └── animations.js       # Sticker tilt effects, grain overlay, smooth scroll & click sparks
```
